ELA
English Language Assistant
AI-powered linguistic infrastructure for English language learning — structured, deterministic, and auditable.

The Problem

1.5 billion people are learning English. The overwhelming majority hit a ceiling when they move from classroom materials to real-world content — lectures, podcasts, technical articles, business meetings. The gap is not vocabulary. It is structure: learners lack a map of how real English sentences are built.

Existing tools avoid the problem. Duolingo simplifies content. LingQ tracks word frequency without analysis. ChatGPT generates a different explanation every time. None produce consistent, auditable, schema-validated linguistic output.

The Solution

ELA is the first platform to combine deterministic NLP parsing with LLM-based enrichment into a validated, schema-enforced JSON contract — the RLE (Recursive Linguistic Elements) schema. Every sentence is broken into a Sentence → Phrase → Word hierarchy, each node annotated with grammar role, tense/aspect/mood, CEFR difficulty level, EN→RU translation, and IPA phonetics.

The output is always the same for the same input. It is auditable, machine-readable, and cheap to produce. A domain-specific T5 model replaces dozens of GPT-4 calls per document — reducing compute cost by an order of magnitude.

What ELA Produces

Bilingual Video (MP4) Original video re-rendered with EN+RU subtitles and dual-language voiceover burned in.
Bilingual Audio (MP3) Each sentence spoken in English then Russian via TTS. Ready for listening practice.
Subtitle Files (SRT) Bilingual, English-only, and Russian-only subtitle files for any video player or editor.
Vocabulary Export All extracted words and phrases with CEFR levels, exportable as JSON or CSV for integration with SRS tools.

Current State

  • Live product at el-a.uk — fully functional, deployed on Hetzner.
  • All ML runs locally — no dependency on OpenAI or other paid APIs by default.
  • Full pipeline implemented — ASR (Whisper), parsing (spaCy), notes (fine-tuned T5), translation (M2M100 418M), phonetics (espeak-ng), CEFR classification.
  • Schema-validated output — RLE v2 contract, frozen-structure validation, regression test suite.
  • Built as Final Year Project, MTU Cork (BSc Software Development, 2025–2026).
