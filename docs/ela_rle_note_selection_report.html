RLE-Based Pedagogical Note Selection in ELA:
Recursive Linguistic Elements,
Structural Abstraction, and Note Dynamics

A contract-based study of whether recursive grammatical structure improves note selection, and how raw versus templated note inventories behave as the number of unique note classes grows

Vladyslav Rastvorov Final Year Student
Department of Computer Science
Munster Technological University
Dr. Nasir Ahmad Supervisor
Department of Computer Science
Munster Technological University
Domain: English Linguistic Analysis (ELA)  ·  Task: RLE contract -> note_id  ·  Repository: github.com/welsol21/FYP_LLM
Abstract

This report evaluates a core claim of the ELA framework: a sentence can be represented as a hierarchy of Recursive Linguistic Elements (RLE), where each node preserves abstract grammatical information rather than lexical identity, and this representation is useful for downstream generalisation. We test this claim through the task of pedagogical note selection. First, we compare a shallow sentence-template classifier against a classifier that receives a richer RLE-derived contract. The richer structural input improves held-out performance from Top-1 = 0.3519 and Top-3 = 0.6037 to Top-1 = 0.3928 and Top-3 = 0.7700. Second, we study how note selection changes as the number of unique note classes grows, comparing raw note labels against templated note labels with placeholders. Raw notes achieve higher absolute accuracy in the tested range, but templated notes show the more favorable dynamic trend as note inventory increases. The results are consistent with the ELA hypothesis, while also indicating that a much larger note inventory will be required for a decisive large-scale study.

1. Conceptual Motivation

The starting point of this work is the thesis claim that natural language is not best represented as a flat stream of words. Instead, each sentence can be decomposed into a recursive hierarchy of linguistic units: sentence, phrase, and word nodes. In the ELA framework, these Recursive Linguistic Elements carry structural attributes such as node type, syntactic role, and tense/aspect/mood, while remaining abstract with respect to concrete lexical identity.

The practical consequence is strong: if the model learns the grammar of structural patterns rather than memorising surface forms, it should generalise to previously unseen vocabulary that instantiates the same grammatical configuration. That is the central idea tested in this report.

Core hypothesis If the input preserves recursive sentence structure in an RLE contract, note selection should improve even when the classifier itself remains comparatively simple. If this effect holds, it supports the claim that grammatical structure, not only lexical content, is a learnable and predictive substrate.

2. Task Definition and Metrics

The prediction task studied here is:

RLE contract input -> note_id

A note_id is a canonical class label pointing to one pedagogical linguistic note. The note text may be either raw natural language or a templated notation containing placeholders such as {{SUBJECT}} or {{IF_CLAUSE}}.

Two ranking metrics are used throughout the report:

  • Top-1: the correct note_id is ranked first.
  • Top-3: the correct note_id appears anywhere among the first three ranked candidates.

Top-1 is therefore the strict measure of exact note selection, while Top-3 indicates whether the correct pedagogical note remains available among the classifier's best immediate hypotheses.

3. Datasets and Experimental Materials

3.1 Contract-input raw-note dataset

The first experiment uses a sentence-level dataset in which the input is a serialized RLE contract (contract_template_v2) and the target is a raw pedagogical note. This dataset contains 3875 rows after balancing and 58 unique raw note targets.

3.2 Large mixed paired-template dataset

The note-dynamics experiment uses a larger mixed source pool with 5016 rows, including 3545 templated targets and 1471 raw targets. This pool is then separated into raw and templated note-id experiments so that both curves can be compared on shared note-cardinality checkpoints.

3.3 Ready dataset examples

Three dataset formats are directly relevant to the thesis:

  • contract-input raw-note dataset
  • paired-template raw-note dataset
  • paired-template templated-note dataset
Dataset interpretation The contract-input dataset is the strongest direct test of the ELA idea because the classifier receives a structural representation derived from the recursive sentence analysis itself, rather than a shallow surface template alone.

4. Experiment A: Does Richer RLE Structure Help?

The first experiment compares two input conditions for note classification:

  • a shallower sentence-template baseline
  • a richer RLE contract representation

The classifier architecture remains tabular in both cases. This is important: any gain can therefore be attributed primarily to the representation, not to a larger neural encoder.

Input condition Top-1 Top-3 Unique note_ids
Shallow sentence-template input 0.3519 0.6037 268
RLE contract input 0.3928 0.7700 58
Main result When the classifier receives a richer RLE-derived contract, note selection improves. This is direct evidence consistent with the ELA thesis claim that structural abstraction carries predictive information.

5. Experiment B: Note-ID Dynamics under Increasing Inventory Size

The second experiment studies how note selection changes as the number of unique note classes grows. Two target regimes are compared on the same source pool:

  • raw note labels
  • templated note labels with placeholders

Shared note-cardinality checkpoints were constructed at 58, 73, 88, and 97 unique note_ids.

The current thesis does not yet reach the many-thousands note regime needed to settle this question decisively.

6. Why Templated Notes Are Harder at Present Scale

The current evidence suggests that templated notes do not underperform because they are underrepresented. In the 58-note setting, they actually have higher average class support than raw notes. Their difficulty is instead linked to class separability.

  • templated notes are longer on average
  • every templated note contains explicit placeholders
  • many templated notes differ only by subtle pedagogical wording or slot choice
  • the resulting class space is dense, with many structurally related neighbours

This means that templating introduces abstraction, but also makes the label space semantically crowded. In other words, abstraction is beneficial only when the downstream class inventory is large and clean enough for that abstraction to become discriminative rather than ambiguous.

8. Thesis-Level Interpretation

Within the scope of this study, the observed behaviour is consistent with the ELA thesis claim.

  • Recursive structural abstraction is useful for pedagogical note selection.
  • A richer RLE contract improves the mapping from sentence structure to note_id.
  • Raw note labels are easier classification targets at moderate inventory sizes.
  • Templated note labels show the more favorable dynamic trend as note inventory expands.
Thesis conclusion The present study supports the claim that the grammar of linguistic structure is learnable from abstract recursive representations. However, it does not yet settle the long-range scaling question, because the note inventory remains far below the many-thousands level that would be required for a decisive large-scale test. The current dynamics should therefore be treated as promising, but not final.
