Problem & Motivation

Language-learning platforms rely on pre-simplified materials. Authentic English — films, podcasts, news — is linguistically rich but cognitively inaccessible without structural guidance. Simplification destroys the input; learners never encounter real language.

Hypothesis: Deterministic NLP and lightweight generative AI can explain authentic input without altering it — producing hierarchical annotations that scaffold meaning while preserving full linguistic complexity.

  • How can a hybrid NLP + LLM pipeline produce accurate pedagogical annotations from authentic media?
  • What data model captures recursive linguistic relations while remaining human-interpretable?
  • Can bilingual visualisation reduce cognitive load?

The RLE Data Model

Core innovation: every sentence is a nested JSON hierarchy at three levels — Sentence → Phrase → Word — validated against a dual-schema contract before persistence.

Sentence
  └── Phrase (NP / VP / PP / ADJP)
       └── Word
            ├── translation
            ├── CEFR level (A1–C2)
            ├── POS & IPA
            ├── TAM (Tense–Aspect–Mood)
            └── note (T5-generated)

Schema is language-agnostic. Current focus: English → Russian. Pluggable translator backends support additional target languages.

The Key Insight: Placeholder-Driven Learning

Fine-tuning T5 on raw linguistic notation failed to generalise. The breakthrough was replacing lexical tokens with structural placeholders:

❌ Raw: "She gave him a book" → [VP gave][NP him]

✅ Template: [SUBJ][V-PAST][IOBJ][DET][NOUN]
        → [TAM: past-simple][VOICE: active]

The abstract grammatical pattern — not the words — became the unit of learning. The model generalises to novel vocabulary because the pattern is invariant to lexical substitution.

This is closed-system behaviour: the internal pattern imposes structure on any incoming context — regardless of whether that context was seen during training.

Implication for Agentic AI

An LLM agent navigating the real world is a closed system operating in an open environment. Its trained patterns are fixed; the world's context is not. The duality principle predicts exactly where agents succeed (stable structural patterns) and fail (distribution shift beyond the trained pattern's boundary).

Understanding training as pattern-carving and inference as pattern-imposing offers a new lens for agent reliability research.

Conclusions

  • Explainable AI annotation makes authentic English pedagogically accessible without simplification.
  • The RLE schema is a viable, human-interpretable model of recursive linguistic structure.
  • The Context–Pattern Duality, observed empirically during T5 fine-tuning, generalises beyond NLP to any learning system that transitions from open-world training to closed-system inference.
  • Placeholder-driven T5 fine-tuning generalises to novel vocabulary because the abstract structural pattern is lexically invariant.
